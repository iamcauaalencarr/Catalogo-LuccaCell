# Catálogo Lucca Cell

Aplicação web do Catálogo Lucca Cell construída com React, Vite, TailwindCSS e Supabase.

## Execução Local

```bash
# Iniciar o frontend no ambiente de desenvolvimento
pnpm --filter @workspace/lucca-cell-catalogo dev
```

O catálogo estará disponível em: `http://localhost:3000`

## Build de Produção

```bash
# Executar o build para produção
pnpm --filter @workspace/lucca-cell-catalogo run build
```

O build será gerado na pasta `dist/`.
